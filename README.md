# IoT Factory Monitor

Manufacturing IoT pipeline: MQTT to time-series database to live dashboard.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Status: in development](https://img.shields.io/badge/status-in%20development-orange)

> **Status:** in active development. Star or watch the repo to follow progress.

## Features

- Sensor simulator for temperature, vibration and machine status
- MQTT ingestion into TimescaleDB
- Prebuilt Grafana dashboards for OEE, downtime and sensor trends
- Threshold-based alerts
- Whole stack starts with one command

## Tech stack

- MQTT (Mosquitto)
- Python ingestion service
- TimescaleDB
- Grafana
- Docker Compose
